About PREDICTOR (VisionClassify)

Production-ready AI Computer Vision Image Classification Web Application.

🧠 Machine Learning Pipeline

PREDICTOR uses a singleton TensorFlow / Keras convolutional vision model stored in ml/model.keras paired with dynamic class definitions in ml/class_names.json.

  • Single-load Architecture: The Keras model loads once per worker process for low-latency inference.
  • Pillow EXIF Orientation: Automatically corrects mobile portrait/landscape rotation tags.
  • OpenCV Preprocessing: Resizes and normalizes RGB tensors before neural network forward pass.
  • Top-K Confidence Calibration: Returns Top 3 & Top 5 class probabilities and processing time.

📱 Mobile-First & PWA Ready

Engineered with a single responsive codebase that adapts across all 7 screen breakpoints from 320px small phones up to 1440px+ widescreen monitors.

  • Touch Targets: All interactive buttons meet or exceed 44px × 44px accessibility standards.
  • Dual Camera Support: Supports live browser WebRTC camera streaming and native mobile capture="environment".
  • Progressive Web App: Includes manifest.json and service-worker.js for offline shell caching and home-screen installation.
  • Dark & Light Themes: Automatically detects OS preference and persists manual overrides in localStorage.

🔌 REST API Endpoint

Integrate PREDICTOR directly into mobile apps, scripts, or microservices:

POST /api/classify/
Content-Type: multipart/form-data
Form Field: image=<file>

Response (200 OK):
{
  "success": true,
  "prediction": "cat",
  "confidence": 0.9642,
  "top_predictions": [
    {
      "class": "cat",
      "confidence": 0.9642
    }
  ]
}

🔒 Security & Deployment

  • CSRF protection on all state-changing requests.
  • File size cap (10 MB), extension whitelist, MIME check, and Pillow binary header verification.
  • UUID-randomized safe upload filenames preventing path traversal.
  • Ready for PostgreSQL, Gunicorn, and WhiteNoise on Render, Railway, AWS, GCP, Azure, or VPS.
